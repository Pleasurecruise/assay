# Moiré Protocol 规格

> 状态：设计冻结（2026-07-24）。实现排在 regime 接线与"每变体日收益落盘"之后；本文档是届时的施工图。
> 原则：矛盾对预枚举、实验从模板选、合成按阈值走；LLM 只填参数和写行文，不发明实验、不改判。

## 1. 矛盾对清单（首版三对）

| ID  | 触发谓词（全部满足才触发）                                                                                              | 判别实验                                                                           | 合成规则                                                                                                                                    |
| --- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| M1  | param-robustness = fail（保留率 < 40%）**且** regime-dependency 证据显示收益集中（主导环境盈亏贡献 > 70%）且该项未 fail | 把参数网格各变体的日收益按环境标签切开，分环境重算保留率（**纯后处理，不重回测**） | 主导环境内保留率 ≥ 70% 且其余环境 < 40% → param 结论细化为"参数脆弱性集中于非主导环境"，写入 `refinedByMoire`；否则维持原结论并记录实验结果 |
| M2  | data-availability = fail（修正差 ≥ 2pp）**且** cost-stress 结论基于未修正基线                                           | 在 PIT 修正基线上重跑 cost_ladder（一次引擎调用）                                  | 修正后成本结论档位变化 → 以修正版为准，`refinedByMoire` 注明；无变化 → 记录"成本结论对成分修正稳健"                                         |
| M3  | homogeneity = fail（与某对照因子相关 ≥ 0.9）**且** param-robustness = pass                                              | 对照经典因子自身跑一次基线（一次引擎调用）                                         | 经典因子夏普 ≥ 被审信号的 80% → homogeneity 细化为"稳健但无增量信息"；否则维持                                                              |

正交组合明确不算矛盾（如 cost fail + param pass），不触发任何实验。

## 2. 实验模板库

仅上表三种：`regime_slice_of_grid`（后处理）、`corrected_cost_ladder`（引擎 1 次）、`benchmark_classic_factor`（引擎 1 次）。Moiré 不得发明第四种。

## 3. 预算与调度

- 每次审计追加实验 ≤ 2 个；多对同时触发按"能否改变最终判决"排序，取前二；
- 16 分钟 cutover 后放弃未启动实验，未决矛盾原样写入报告（不转硬结论）；
- 未决且可能改判 → 受影响检查按 VERDICT_SPEC 转 insufficient_evidence。

## 4. 合成的确定性

所有阈值（40%/70%/2pp/0.9/80%）集中于 contracts 常量并版本化；同输入同缓存 → 同合成结论。

## 5. LLM 边界

Moiré 编排 agent 只做三件事：按 §1 谓词核对是否触发（谓词判定本身主机可复核）；给模板填参数（如选环境维度 trend/vol）；撰写 `refinedByMoire` 与报告行文。禁止：新增实验类型、修改阈值、推翻合成结果。

## 前置条件（实现顺序约束）

- M1 依赖 grid 每变体日收益落盘为工件（随 regime 接线一并实现，是"加固缓做"原则的唯一例外）；
- M2 依赖 PIT 修正基线（data-availability 接线产物）；
- M3 依赖 homogeneity 接线与自建对照因子。
